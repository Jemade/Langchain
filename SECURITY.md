# Security

Do not publish credentials or sensitive shipment records in issues. Report vulnerabilities privately through GitHub's private reporting feature if enabled, or contact the maintainer privately via their profile contact channel. No response-time guarantee is offered.

This MVP has one shared reviewer credential and no tenant or per-user identity boundaries. Run locally or through an authenticated operator tunnel. Model prompts do not eliminate prompt injection; no autonomous external actions are provided. Review all drafts. Rotate exposed credentials and inspect prior Git history when investigating an exposure.
